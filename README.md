# ABISMO: O sino afogado

Jogo de exploração e puzzles em JavaScript puro, ambientado em três partes de uma caverna aquática: A Gruta Luminosa, O Salão de Cristais e A Catedral Submersa.

## Como jogar

Abra `index.html` em um navegador moderno. Não é necessário instalar Node.js, dependências ou iniciar um servidor.

- `A` / `D` ou setas: nadar para os lados
- `W` / seta para cima: subir na água
- `S` / seta para baixo: mergulhar; no fundo, agachar e esconder-se
- `Espaço`: dar uma braçada forte para ganhar impulso para cima
- `E`: interagir com um mecanismo quando estiver perto dele

Cada fase tem um puzzle próprio:

- **A Gruta Luminosa:** nade entre diferentes alturas e ative os três relés na ordem, da esquerda para a direita. Uma ordem errada reinicia a sequência.
- **O Salão de Cristais:** alcance o gerador e pressione `E` três vezes quando o pulso indicar o pico verde.
- **A Catedral Submersa:** nade até as duas correntes, posicionadas em alturas diferentes, e solte ambas; a ordem não importa.

Depois de resolver o puzzle, atravesse até a escotilha. Agache para se esconder da criatura. Se ela alcançar você, a fase recomeça. O botão SOM alterna os efeitos sonoros.
